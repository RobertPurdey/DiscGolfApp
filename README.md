An android application that allows people to create accounts, add friends and track disc golf games securely. The focus was on sending/receiving encrypted data as well as broadcasting and receiving live score updates.

This application talks to my API, https://github.com/RobertPurdey/FrolfApi, for data and uses my TCP broadcaster, https://github.com/RobertPurdey/FrolfAppScoreBroadcaster, to send live data to and listen for it.

This project is part of my BCIT bachelor practicum. See https://github.com/RobertPurdey/bcit-bachelor-practicum-documentation/blob/main/live-scoring-app-bcit-practicum-final-report.pdf for full documentation of the practicum.
